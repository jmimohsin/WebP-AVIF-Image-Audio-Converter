WebP/AVIF Image & Audio Converter makes it easy to work with modern image formats and audio media while browsing. Find images and audio files on any website, download supported media, convert images into popular formats, and open files directly in free Coders Hub online tools.

### 🖼️ Image Detection & Download
- Automatically find images on the current webpage.
- Detect WebP, AVIF, SVG, and other large images.
- Download images in PNG or JPG format.
- Convert modern image formats into widely supported formats.
- Quickly access image actions through the right-click context menu.

### 🎵 Audio Detection & Download
- Detect audio media available on the current webpage.
- Download detected audio files.
- Access audio actions directly through the right-click context menu.
- Open audio files in online audio tools for trimming and conversion.

### 🖱️ Quick Context Menu Actions

Right-click on an image or audio file to access useful actions without opening the extension popup.

**Image actions:**
- Save as PNG
- Save as JPG
- Save as WebP

**Audio actions:**
- Download audio
- Trim audio
- Convert audio

### 🛠️ Coders Hub Integration

Open selected media directly in free Coders Hub online tools.

Available tools include:
- Image Compressor
- Image OCR
- Watermark Remover
- Audio Trimmer
- Audio Converter

Explore more tools at [Coders Hub](https://coders-hub.com/).

## 🚀 How to Use

1. Install the extension from the Chrome Web Store or Microsoft Edge Add-ons.
2. Open any webpage containing images or audio.
3. Click the extension icon to discover available media.
4. Select an image or audio file.
5. Download, convert, or open it in a suitable Coders Hub online tool.

**Quick alternative:** Right-click directly on an image or audio file to access available actions instantly.
